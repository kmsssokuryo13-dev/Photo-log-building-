# 建物登記 写真台帳作成アプリ

建物登記に必要な写真台帳（外観・内装）を作成するWebアプリケーションです。

## 機能

- **外観写真管理**: 写真をアップロードし、自動で方向ラベル（A, B, C...）を付与
- **内装写真管理**: グループ設定に応じたキャプション（居宅 内部、算入/不算入など）を自動付与
- **ドラッグ＆ドロップ並べ替え**: 写真の順序を直感的に変更可能
- **写真の回転**: 90度回転に対応
- **外観⇔内装の移動**: 選択した写真を外観・内装間で移動可能
- **PDF出力**: A4用紙に最適化された印刷レイアウトで出力
- **画像圧縮**: アップロード時に自動圧縮（最大1200px、品質80%）

## セットアップ

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

## 技術スタック

- React + TypeScript
- Vite
- Tailwind CSS v4
- @dnd-kit（ドラッグ＆ドロップ）
- Lucide React（アイコン）
